# Основные команды Git

Git — система контроля версий.

## Работа с репозиторием

| Команда | Описание |
|---------|----------|
| `git init` | Инициализация репозитория |
| `git clone <url>` | Клонирование репозитория |
| `git status` | Просмотр статуса файлов |
| `git add .` | Добавление изменений в индекс |
| `git commit -m "message"` | Создание коммита |
| `git push` | Отправка изменений на удалённый репозиторий |
| `git pull` | Получение изменений из удалённого репозитория |

## Ветки

```bash
git branch              # список веток
git branch feature      # создание ветки
git checkout feature    # переключение на ветку
git checkout -b feature # создание и переключение
git merge feature       # слияние ветки в текущую
```

## Отмена изменений

```bash
git restore file.txt    # отменить изменения в файле
git reset --soft HEAD~1 # отменить последний коммит
```
