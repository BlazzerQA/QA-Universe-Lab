# Java Collections

Коллекции в Java — это фреймворк для хранения и обработки групп объектов.

## Основные интерфейсы

- `List` — упорядоченная коллекция, допускает дубликаты.
- `Set` — коллекция уникальных элементов.
- `Map` — пары «ключ-значение».
- `Queue` — очередь с FIFO-доступом.

## Популярные реализации

| Интерфейс | Реализация | Особенности |
|-----------|------------|-------------|
| List      | ArrayList  | Быстрый доступ по индексу |
| List      | LinkedList | Быстрое добавление/удаление |
| Set       | HashSet    | Уникальные элементы, негарантированный порядок |
| Set       | TreeSet    | Отсортированные элементы |
| Map       | HashMap    | Быстрый доступ по ключу |
| Map       | TreeMap    | Отсортированные ключи |

## Пример

```java
List<String> list = new ArrayList<>();
list.add("Test");
Set<String> set = new HashSet<>(list);
```

## Полезные методы Stream API

- `filter()` — фильтрация элементов
- `map()` — преобразование элементов
- `collect()` — сбор результата
- `forEach()` — итерация
