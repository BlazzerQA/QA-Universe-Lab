# Аннотации JUnit 5

JUnit 5 — основной фреймворк для юнит-тестирования в Java.

## Основные аннотации

| Аннотация | Назначение |
|-----------|------------|
| `@Test` | Помечает метод как тест |
| `@BeforeEach` | Выполняется перед каждым тестом |
| `@AfterEach` | Выполняется после каждого теста |
| `@BeforeAll` | Выполняется один раз перед всеми тестами |
| `@AfterAll` | Выполняется один раз после всех тестов |
| `@DisplayName` | Задаёт человекочитаемое имя теста |
| `@Disabled` | Отключает тест |
| `@ParameterizedTest` | Параметризованный тест |
| `@ValueSource` | Источник простых значений для параметризации |

## Пример

```java
@Test
@DisplayName("Проверка суммы двух чисел")
void shouldReturnSum() {
    assertEquals(5, calculator.add(2, 3));
}
```
